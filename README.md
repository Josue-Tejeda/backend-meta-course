# Meta Backend Developer Certificate Projects

A comprehensive showcase of assignments, database schemas, and API code built during the **Meta Backend Developer Professional Certificate** program.

## 🎓 Certificate Overview

The Meta Backend Developer Professional Certificate is a rigorous training program covering the essential technologies required to design, build, and optimize backend applications. Key learnings include:
- Programming in Python (data structures, object-oriented concepts, unit testing).
- Database administration, SQL query creation, and PostgreSQL configuration.
- Designing and implementing REST APIs using **Django REST Framework (DRF)**.
- Deploying full-stack applications with modern authentication and authorization.

---

## 🚀 Highlighted Capstone Project: Little Lemon API

The final capstone project demonstrates end-to-end backend design:
*   **Django Backend Architecture**: MVC layout routing menu requests, reservations, and customer comments.
*   **Token-Based Authentication**: Secure authentication endpoints allowing users to sign up, sign in, and access protected resources.
*   **RESTful Routing**: API endpoints with validation, serialization, and filtering capabilities.
- **Relational Schema**: A PostgreSQL/MySQL database setup with tables for Menu Items, Booking System, and User credentials.

## 🛠 Modules Completed

1.  **Introduction to Back-End Development**: Server basics, client-server models, HTTP requests.
2.  **Programming in Python**: Custom scripts, file manipulation, sorting algorithms, and standard libraries.
3.  **Version Control**: Git workflow, staging, branching, conflict resolution.
4.  **Introduction to Databases**: Relational database systems, SQLite, MySQL queries.
5.  **Django Web Framework**: Models, views, templates, routing, admin dashboards.
6.  **APIs**: REST API design, serialization, Django REST Framework, authentication tokens.
7.  **The Full Stack**: Linking backend Django services to frontend Web clients.
8.  **Back-End Capstone**: Developing the full API suite and database relations for the Little Lemon restaurant.
